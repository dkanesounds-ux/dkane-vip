## Deploy on Render
1. Create a GitHub repository.
2. Upload:
   - index.html
   - style.css
   - render.yaml
3. In Render choose New + -> Static Site.
4. Connect the GitHub repository.
5. Leave Build Command blank.
6. Set Publish Directory to `.`
7. Deploy.

Use the Render URL in TikTok.
